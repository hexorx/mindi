# P7 drone build handoff

Build from the repository root using `apps/agent-box-hermes/Dockerfile` on
linux/amd64, or use **`stacks/agent-box-hermes/compose.p7.yaml` as the sole compose
file**, always with `--project-directory <repo root>` (including when invoked
from the root). The build context is relative to that explicit project directory:

```sh
docker compose --project-directory . --env-file stacks/agent-box-hermes/.env -f stacks/agent-box-hermes/compose.p7.yaml config
```

Do not combine it with the desktop compose file, which publishes a host
port. P7 has no `ports`, host networking, privileged mode or tailnet service.

The single network entrypoint is **HTTPS container port 8443**. The native Hermes
API binds only `127.0.0.1:8642`; `/v1/*`, `/api/*`, and `/health` are proxied through
8443 with Bearer auth passed unchanged. Streaming is unbuffered. Desktop Basic
auth still protects all other routes. Use `https://<private-box-name>:8443` as the
adapter base URL (no `/v1` suffix). Health path: **`/health`** (Hermes API liveness);
the Docker health check additionally requires working desktop capture and the
P4 memory database. Clients should send the API Bearer credential for health too.
For the approved Traefik route, configure an HTTPS upstream to port 8443 with
certificate trust and a preserved Host header. Limit the P7 router to `/v1/`,
`/api/`, and `/health` paths; desktop access stays internal unless Opi provisions
the separately approved authenticated desktop route.

## Runtime inputs

Set these through Dokploy/runtime secrets, never build arguments or git:

- `API_SERVER_KEY`: dedicated box Bearer key, at least 16 characters; use a random
  high-entropy value accepted by Hermes. Missing/invalid input fails startup.
- `PAPERCLIP_CALLBACK_KEY`: separate dedicated test-agent callback credential,
  at least 16 characters. It remains available to the gateway/tool environment;
  this service does not implement callback forwarding or validate the protocol.
- `PAPERCLIP_API_URL`: Paperclip HTTP(S) URL reachable from the box, normally
  including `/api`. No embedded credentials, query, or fragment.
- Provider credentials/model configuration for actual Hermes inference, using
  the existing operator configuration mechanism. Boot tests make no model calls.

Compose requires these six host file path variables, mounted as runtime secrets:
`DESKTOP_PASSWORD_FILE`, `DESKTOP_TLS_CERT_FILE`, `DESKTOP_TLS_KEY_FILE`,
`MEMORY_LLM_KEY_FILE`, `MEMORY_EMBEDDINGS_KEY_FILE`, `INFERENCE_API_KEY_FILE`. For a direct Dockerfile build,
mount their contents read-only at `/run/secrets/desktop_password`,
`/run/secrets/desktop_tls_cert`, `/run/secrets/desktop_tls_key`,
`/run/secrets/memory_llm_key`, `/run/secrets/memory_embeddings_key`,
`/run/secrets/inference_api_key` respectively.
The TLS certificate must cover the private hostname and be trusted by Paperclip.
Empty provider overrides retain the OpenAI defaults. For the approved z.ai test
box, use the configuration below with this compose file alone.

Persist **`/home/agent`** and **`/var/lib/agent-box/hindsight`** as separate volumes.
Use a fresh matching pair for the disposable P7 box; the memory volume is bound
to the home volume identity. The P7 compose sets the approved 4 CPU / 8 GiB memory limits, 2 GiB shared memory,
`unless-stopped` restart, 10 MB × 3 log rotation, and 20 seconds to stop.

## z.ai coding plan: memory and Hermes inference

Set these non-secret Dokploy environment values; compose passes all six through:

```dotenv
MEMORY_LLM_PROVIDER=openai
MEMORY_LLM_MODEL=glm-5.3-flash
MEMORY_LLM_BASE_URL=https://api.z.ai/api/coding/paas/v4
MEMORY_EMBEDDINGS_PROVIDER=local
MEMORY_EMBEDDINGS_MODEL=BAAI/bge-small-en-v1.5
MEMORY_EMBEDDINGS_BASE_URL=
```

`MEMORY_LLM_KEY_FILE` must point to Opi's staged z.ai `memory_llm_key` file.
**`MEMORY_EMBEDDINGS_KEY_FILE` and the `memory_embeddings_key` mount remain
required** by compose and startup validation, even in local mode. Mount a file
containing the non-secret string `local-unused` (nonempty, one line). Local mode
never sends that placeholder to a provider; it emits no OpenAI embeddings key,
URL or model settings. No OpenAI credential is needed.

The image installs CPU-only PyTorch 2.8.0 and sentence-transformers 5.1.0.
On the first local-mode boot, BGE weights download from Hugging Face into
`/var/lib/agent-box/hindsight/huggingface` (`HF_HOME`), inside `box-memory`.
Allow outbound HTTPS to Hugging Face and its download hosts, and allow time for
this initial download before diagnosing readiness. Subsequent boots reuse that
cache; embedding computation has no paid API calls. Remote model code is disabled,
CPU use is forced, and reranking stays `rrf`. The larger image and first-start
latency are intentional. Use the fresh matching home/memory volumes planned for
P7: changing embedding models on an existing populated database requires a
separate re-embedding/migration plan, not an in-place config flip.

### Hindsight compatibility

Source inspection of the published `hindsight-api-slim==0.6.1` wheel confirms
that `openai` accepts the overridden base URL and uses chat completions.
Normal retain/reflect structured calls default to `strict_schema=False`: the
provider puts the schema in the prompt, requests `response_format={"type":
"json_object"}`, then parses/validates the result. No internal caller in that
version enables strict schema mode. This matches
[z.ai's documented JSON mode](https://docs.z.ai/guides/capabilities/struct-output).
The same version also has a native `zai` provider whose default URL is the coding
endpoint, using that same compatible implementation; this box keeps its existing
`openai` selector with the explicit URL above.

Therefore the protocol path is compatible; there is no requirement for OpenAI
strict `json_schema` support on this path. Use `glm-5.3-flash`, which Opi already
verified returns 200 with this coding-plan key. This is source/documentation
verification, **not a live structured-output or retain/recall pass** on that model.
Opi must verify a retain followed by recall on the test box within the existing
call budget. No paid calls or credential reads were made for this source change.
Do not use the general `/api/paas/v4` endpoint for this key.

References: [Hindsight 0.6.1 source](https://github.com/vectorize-io/hindsight/tree/v0.6.1/hindsight-api-slim/hindsight_api/engine),
[release notes](https://hindsight.vectorize.io/blog/2026/05/08/version-0-6-1).

### Hermes inference is separate

`memory_llm_key` is consumed only by Hindsight. It does **not** configure Hermes.
Set these optional non-secret Dokploy variables together (only `zai` is supported):

```dotenv
HERMES_INFERENCE_PROVIDER=zai
HERMES_INFERENCE_MODEL=glm-5.3-flash
HERMES_INFERENCE_BASE_URL=https://api.z.ai/api/coding/paas/v4
INFERENCE_API_KEY_FILE=<Dokploy-mounted inference_api_key file path>
```

Stage the z.ai key as the Dokploy file `inference_api_key`; compose mounts it at
`/run/secrets/inference_api_key`. The host path variable is required, even when
inference overrides are empty. It may point to the same staged key file as
`MEMORY_LLM_KEY_FILE`; no key value belongs in compose environment or git.

Before config activation, bootstrap writes the initial `model` mapping with
`provider`, `default`, and `base_url` and seeds `.hermes/.env` with `GLM_API_KEY`
and `GLM_BASE_URL`. Both files are created only when absent, owned by 1000:1000,
mode 0600, under the 0700 `.hermes` directory. Existing configs (including managed
symlinks) and existing `.env` files are preserved on restart; changing these
inputs does not rotate existing credentials or reconfigure an initialized home.
All-empty overrides disable seeding; incomplete or invalid overrides fail closed
with redacted bootstrap errors. No manual volume staging is required.

The key persists in the private home, so protect its backups as secret-bearing.
Config activation preserves the model mapping while adding memory/computer-use
settings. This boot path makes no inference calls.

## Scope and rollback

This branch includes P4 PR #6 at `d450f4249b4da1dafbeb0396256560fb1e862cbb`
and main at `c1b70d97a4e1ce249d29e634fd099f78a55b0eac`. It excludes P6 PR #7.
Opi owns the approved drone build/deployment; this change publishes source only.
Protocol auth, streaming/reconnect/cancel/dedup, callback proof, serialized desktop
runs and timer-off behavior remain acceptance work on HEX-95. Starting the native
gateway can activate its scheduler: use a fresh test home with no scheduled jobs;
this branch does not claim timer suppression or enforce concurrency limits.

Rollback: stop the test box, disable the disposable gateway agent, revoke its
API/callback credentials, and return to the previous pinned build/configuration.
Preserve both volumes; restore matching backups together if needed. Do not delete
volumes or run shared-database migrations.

Unit tests cover env propagation, redacted failures, private binding, readiness
and the no-host-port compose contract. The container smoke adds actual upstream
API auth checks through TLS without inference. Docker is required to execute that
smoke; local Python/Node tests do not establish P7 protocol acceptance.
